## 📖 نظرة عامة (Overview)

**ZHR Synergy Cinema Intro & Voice-Over Studio** هو بيئة عمل ومحرر تفاعلي متقدم مصمم لصنّاع المحتوى ومخرجي الأفلام ومصممي الموشن جرافيك بالعربي. يوفر توليداً صوتياً سينمائياً فائق الواقعية عبر سحابة Google Gemini، مع الحفاظ الحرفي التام على نصوص السكربت بنسبة 100%، وتوجيه النبرات والمشاعر والوقفات الدرامية عبر نظام **وسوم الإلقاء السريع (Speech Markup)**.

---

## ✨ المميزات الرئيسية

### 1. 🎭 محرك التوجيه الصوتي والسينمائي المتكامل
- **العزل الإخراجي التام للتوجيهات (Strict Isolation):** يتم فصل توجيهات المخرج ونبرات الصوت وعزلها برمجياً لضمان عدم نطق أي كلمة إرشادية في التسجيل الصوتي النهائي.
- **القضاء على نقرات ونهايات الصوت (EOS Vocoder Glitch Elimination):** فلترة ومعالجة نهاية البايتات وإضافة خفوت تدريجي (Cosine Fade-out) لمنع أي تشويش عند نهاية الملفات.
- **دعم التشكيل الآلي للغة العربية:** ضبط أواخر الكلمات والهمزات بنقرة واحدة لتحسين فصاحة النطق.

### 2. ⚡ وسوم الإلقاء السريع (Speech Markup Tags)
إدراج فوري لتوجيهات الأداء المباشرة داخل النص دون استهلاك كريديت إضافي:
- **الوقفات والتنفس:** `[وقفة: ثانية]`، `[وقفة: نصف ثانية]`، `[وقفة درامية]`، `[تنفس عميق]`.
- **المشاعر والنبرات:** `[بحماس]`، `[بهدوء]`، `[بجدية ورصانة]`، `[بغموض وتشويق]`، `[بهمس]`، `[بثقة واعتزاز]`.
- **السرعة والتوكيد:** `[بسرعة]`، `[ببطء وتأنٍ]`، `[توكيد قوي]`، `[نبرة ختامية]`.
- **البودكاست والحوار الثنائي:** `[المقدم: سعد]`، `[الضيف: منى]`، `[ضحكة خفيفة]`.

### 3. 💾 نظام حفظ وإدارة البريسيتات المخصصة (Custom Presets)
- حفظ عدد لا نهائي من البريسيتات بنمط ألوان باوهاوس الـ 6، واختيار الأيقونة الهندسية.
- إمكانية تعديل العنوان، الوصف، الصوت، والميكسر وإعادة الحفظ في نفس المكان أو حفظ نسخة جديدة.
- يتضمن الاستوديو نموذجين جاهزين:
  - 🎬 **نموذج وسوم الإلقاء السريع:** لتعلم أساليب التوجيه الدرامي.
  - 🎙️ **نموذج بودكاست ثنائي تفاعلي:** لتعلم محاكاة الحوارات بين شخصيتين.

### 4. 📊 إدارة ومزامنة المصروف وسقف الصرف الشهري (Monthly Spend Cap)
- مطابقة دقيقة لحساب التكلفة مع تسعيرة **Audio Output Tokens** الرسمية ($20.00 لكل 1M توكن).
- زر تحكم يدوي لضبط رقم الاستهلاك الفعلي (مثال: `$3.23 / $4.00`).
- زر تصفير العداد لبدء دورة حسابية جديدة.
- سجل هيستوري كامل لجميع الطلبات مع إمكانية التصدير إلى **CSV (Excel)** و **JSON**.

## 🚀 التثبيت والتشغيل (Quick Start)

### المتطلبات الأساسية
- Node.js v18+
- Python 3.10+
- FFmpeg (متاح في مسار النظام)
- مفتاح Google Gemini API Key

### خطوات التشغيل
1. استنساخ المستودع:
```bash
git clone https://github.com/adamretouche/zhr-synergy-cinema-vo-studio.git
cd zhr-synergy-cinema-vo-studio
```

2. تثبيت الحزم:
```bash
npm install
```

3. ضبط المفاتيح:
قم بإنشاء ملف `.env`:
```env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```

4. التشغيل:
```bash
npm run dev
# أو تشغيل الخادم المستقل
npm run server
```
افتح المتصفح على: `http://localhost:3000`
